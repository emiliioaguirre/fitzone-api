<h1 align="center">FitZone en Postman</h1>

Me apoyé en IA para preparar esta colección de peticiones y organizar las llamadas a la API.

Importar [FitZone.postman_collection.json](FitZone.postman_collection.json) desde **Import > Files**. Iniciar la API y ejecutar las 29 peticiones en orden.

Las peticiones registran las tres sucursales, socios y clases de ejemplo. Comprueban membresía, cupo, inscripción y avisos. La última consulta espera el horario preparado para verificar el recordatorio, conservando la regla de dos horas.

Los ejemplos se incluyen con fines prácticos para comprender el proceso y las reglas del servicio.
